# Writing

Read `docs/WRITING.md` before you write. It is the guide, and this skill only says when to use it.

1. Write the draft.
2. Check it against each rule in `docs/WRITING.md`, one rule at a time.
3. Rewrite every sentence that breaks one. Don't explain the rewrite.

For code comments, also follow the comment rules in `docs/GUIDELINES.md#comments`.
